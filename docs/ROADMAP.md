# Roadmap

1. **Protótipo navegável** (`index.html`): pronto.
2. **Supabase:** esquema, Auth com papéis aluno/admin, Storage para vídeos.
3. **Stripe:** checkout dos três produtos e webhook de matrícula.
4. **Área do aluno real:** trilha sequencial, progresso e certificado em PDF.
5. **Área do admin real:** cadastro de cursos, calendário, upload de vídeo.
6. **Vídeo ao vivo:** sala com LiveKit e ferramentas (fundo, legendas e resumo por IA, enquetes, cronômetro, salas de networking, transmissão) prontas em modo demonstração; falta ligar o projeto LiveKit real (docs/LIVEKIT.md).
7. **Comunicação:** e-mails (Resend), WhatsApp e lembretes automáticos.
8. **Live para gravado:** pipeline de compilação em módulos.
